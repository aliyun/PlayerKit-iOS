# **AliPlayerKit Documentation Index**

**AliPlayerKit** is a set of business-oriented **low-code player UI components** and **scenario-based solutions**. Through high-level encapsulation of player capabilities and UI interactions, it helps customers quickly build app playback capabilities with minimal integration effort, without directly calling low-level player APIs or implementing complex player UIs.

This documentation index introduces the content and purpose of each document, organized by the recommended learning and usage flow.
